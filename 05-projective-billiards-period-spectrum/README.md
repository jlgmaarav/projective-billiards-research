# The period spectrum of reflective projective billiards

**Status:** Manuscript in preparation; not peer-reviewed.

This folder contains the standalone manuscript snapshot compiled on 3 October 2026 and its verifier scripts.

- [Manuscript PDF](main.pdf)
- [LaTeX source](main.tex)
- [Computational verifiers](verificadores/)

The manuscript studies period existence for bounded polyhedral projective billiards with central facet fields, using joins and suspensions, and gives metric obstructions. It is intended to be read as a self-contained manuscript; its claims have not been peer-reviewed.

The verifier scripts check specific calculations and constructions; consult their headers for assumptions and invocation details. They supplement, and do not replace, the proofs in the manuscript.
